# Personal Portfolio Demo

A static personal portfolio page built with HTML and CSS. It presents an introduction, skills, education, and contact information.

## Preview

The website source is preserved in [`index.html`](index.html).

## Technology

- HTML5
- CSS3
- Google Fonts (Poppins)

## Run Locally

```bash
git clone https://github.com/dar2006sh8an13/demo..git
cd demo.
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000).

## Customize

Update the page content and styles to reflect current information. Before publishing, review all contact details and remove any placeholders or personal information you do not intend to make public.

## Deployment

This static page can be hosted using GitHub Pages or another static web host.
